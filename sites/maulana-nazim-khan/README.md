# Maulana Nazim Khan – static site

Redesigned, dependency-free version of the original HTML site. Open `index.html` or upload this folder to any static host.

- Same sections, content, phone numbers and image file names as the original (`img/`).
- Hero slider uses `01.jpg`, `02.jpg`, `03.jpg` (autoplay, arrows, dots, swipe).
- No jQuery / Bootstrap / Owl Carousel / Font Awesome / Boxicons — icons are an inline SVG sprite, carousel is `js/main.js`.
- Images recompressed in place (same names); `bg2.webp` is a light animated twin of `bg2.gif` (the GIF stays as fallback).
